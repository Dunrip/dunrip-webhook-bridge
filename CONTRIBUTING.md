# Contributing

Thanks for your interest in contributing to `dunrip-webhook-bridge`.

## Reporting Bugs

Please open a GitHub issue and include:
- A clear description of the problem
- Steps to reproduce
- Expected behavior vs actual behavior
- Logs or screenshots (if relevant)
- Environment details (OS, Python version, app version)

## Suggesting Features

Open a GitHub issue with:
- The problem you want to solve
- Your proposed solution
- Any alternatives you considered

## Development Setup

1. Fork and clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run tests:

```bash
pytest
```

## Pull Request Process

1. Create a branch for your change.
2. Keep commits focused and descriptive.
3. Add or update tests when applicable.
4. Open a pull request with:
   - What changed
   - Why it changed
   - How it was tested
5. Address review feedback promptly.

## Code Style

- Prefer clear, readable Python code.
- Keep functions small and focused.
- Add docstrings/comments only when they improve clarity.
- Follow existing project patterns and naming conventions.
